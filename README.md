# Интернет-магазин (Django)

Учебный / демо-проект интернет-магазина на Django: каталог с иерархией категорий, корзина, избранное, оформление заказа, личный кабинет, рекомендации и трекинг статусов заказов.

## Стек

- Python 3.11+
- Django 4.2
- SQLite (по умолчанию)
- Pillow (изображения)
- django-mathfilters

## Возможности

- **Каталог** — разделы → подкатегории → товары
- **Карточка товара** — варианты цвета/размера (SKU), галерея
- **Поиск** с историей запросов в браузере
- **Корзина и избранное**
- **Оформление заказа** — самовывоз / доставка, контакты, адрес
- **Статусы заказа** — дорожка прогресса для покупателя
- **Суперпользователь** — пошаговые кнопки смены статуса и список всех заказов в профиле
- **Популярные товары и персональные рекомендации**
- Демо-данные с фото: команда `seed_demo`

```
hobbylive-project-django/

    └── media/                 # загруженные фото (создаётся локально)
```

## Быстрый старт

```bash
# клонировать репозиторий и перейти в него
cd hobbylive-project-django

# виртуальное окружение
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate

# зависимости
pip install -r requirements.txt

# миграции и сервер
cd hobbylive
python manage.py migrate
python manage.py createsuperuser  # для админки и управления заказами
python manage.py runserver
```

Открыть: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)  
Админка: [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)

## Демо-каталог

Пересоздаёт категории, товары и фото (старые заказы/корзины очищаются):

```bash
cd hobbylive
python manage.py seed_demo
```

Фото берутся из `hobbylive/static/demo_photos/` и копируются в `media/`.

## Основные URL

| Путь | Описание |
|------|----------|
| `/` | Главная (популярные) |
| `/categories/` | Корневые категории |
| `/products/<id>/` | Подкатегории или товары |
| `/search/?q=…` | Поиск |
| `/popular/` | Популярные товары |
| `/order/` | Оформление заказа |
| `/profile/` | Личный кабинет |
| `/users/signin/` | Вход |
| `/users/signup/` | Регистрация |

## Статусы заказа

Цепочка: **Создан → Собирается → В пути → Доставлено → Получено** (+ **Отменен**).

- Покупатель видит дорожку статусов на странице заказа.
- Суперпользователь двигает заказ кнопками следующего шага (в карточке заказа и во вкладке «Все заказы» в профиле).
- Отмена доступна для статусов «Создан» и «Собирается».

## Разработка

```bash
source venv/bin/activate
cd hobbylive
python manage.py runserver
```

Статика: `hobbylive/static/css/app.css`, `hobbylive/static/js/app.js`.  
Шаблоны: `hobbylive/templates/`.

## Примечания

- По умолчанию БД — SQLite (`hobbylive/db.sqlite3`).
- `DEBUG=True`, для продакшена смените `SECRET_KEY`, выключите debug и настройте `ALLOWED_HOSTS`.
- Медиафайлы раздаются только при `DEBUG=True`; в проде нужен веб-сервер / S3.
